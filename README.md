RetailSmart: Predicción de ventas, segmentación e inventario inteligente
​Prototipo desarrollado para la materia de Fundamentos de IA en la Universidad Tecnológica de León.
Este proyecto integra algoritmos de aprendizaje supervisado, no supervisado, por refuerzo y redes neuronales convolucionales para resolver problemas de toma de decisiones en el sector de comercio y ventas.

Estructura del proyecto:
• ​data/: Almacena los conjuntos de datos crudos (raw/) y procesados (processed/).  
• ​notebooks/: Cuadernos experimentales de Jupyter Lab (01_eda.ipynb, 02_supervisado.ipynb, 03_no_supervisado.ipynb, 04_cnn.ipynb, 05_refuerzo.ipynb).  
• ​src/: Código fuente con funciones reutilizables y la configuración de la clase del entorno de Gymnasium.  
• ​models/: Modelos entrenados y exportados para producción (formatos .joblib, .pt y .npy).  
• ​app/: Código de la interfaz interactiva web desarrollada en Streamlit (app.py).  
​• reports/: Informe técnico final en PDF, figuras generadas y presentación de diapositivas.
